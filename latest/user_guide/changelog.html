Changelog#

Release notes for the wheels documented on this site. Version numbers refer to gs-nyx (renderer) and gs-nyx-plugin (Genesis integration).

gs-nyx 0.1.9 / gs-nyx-plugin 0.1.10#

New#

  • AMD GPUs through ROCm. The renderer no longer bundles a CUDA runtime. Its buffers are exported as OS handles and imported into whichever compute API PyTorch was built for, CUDA or HIP, by the new gs_nyx.nyx_external_memory module. A ROCm build of PyTorch drives AMD GPUs with no change in user code, on Windows 11 and Linux. See GPU backends: CUDA and ROCm.

  • GPU selection. gpu_vendor picks the vendor Nyx renders on; by default the GPU with the most memory is used (EPickStrategy, EGPUVendor).

  • Batched multi-environment rendering. Every (env, camera) pair is rendered by a single native call. The plugin uploads the state of all environments in one copy and no longer loops over environments in Python. See Sensor lifecycle.

  • Camera profiles. camera_profile references a CameraProfileAsset JSON file describing lens, sensor and colour management. A Sony A7R V / 24 mm profile ships with the wheel. See Camera profiles.

  • Tone mappers. Neutral and ACES_1_3 join Off, Reinhard and LUT in EToneMapper.

  • Parallax-corrected environment maps. EnvironmentMapAsset gains parallax (EEnvMapParallax) and the parallax_box_* fields. See Environment maps.

  • Transmissive materials in the SDK. MaterialAsset exposes transmission, thickness, absorption and ior. The plugin does not map Genesis Glass / Water surfaces to them yet.

  • Log control. set_log_flags() / log_flags() select which ELogLevel levels the native library prints.

  • Scene reload. reload() re-imports only the assets that changed on disk.

  • Python 3.13 is now a supported interpreter.

Breaking changes#

  • NyxCameraOptions.tone_mapper was removed. Set the tone mapper in a camera profile instead (Camera profiles).

  • EnvironmentMapAsset.rotation is now expressed in degrees (it was radians).

  • The plugin requires Genesis World 1.4.x (genesis-world>=1.4.0,<1.5.0).

  • NyxCameraOptions.window_size defaults to (1920, 1080) (was (1024, 1024)).

  • Lower-level renderer API: BridgeUpdateData, update_scene_buffers() and BridgeStartupParams.cudaDevice are gone. Buffers are exported with export_buffer() (EBridgeBuffer), the GPU is chosen with pickStrategy / deviceData, and render_batch() replaces the per-camera render_frame return value. NyxPyRenderer keeps a compatible render(camera_index, env_index) and adds render_all() and camera_image().

  • Video encoder: encode_frame_srgb_to_cpu takes only the host output pointer; the input frame is written into the buffer returned by export_input_buffer().
